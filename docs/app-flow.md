# Fluxos principais

## Aluno

```text
Cadastro e consentimento
        -> escolha de concurso e cargo
        -> resolução de questões
        -> envio da resposta
        -> correção comentada
        -> caderno de erros e estatísticas
        -> revisão e novos simulados
```

## Conteúdo editorial

```text
Fonte e taxonomia validadas
        -> criação de rascunho autoral
        -> revisão independente
        -> revisão humana
        -> aprovação e versionamento
        -> publicação controlada
```

## Assinatura

```text
Escolha do plano
        -> checkout no provedor de pagamento
        -> confirmação validada no servidor
        -> concessão de acesso
        -> acompanhamento ou cancelamento pela conta
```

Falhas de pagamento, mensagens duplicadas e tentativas de manipulação do
navegador não devem conceder acesso.
