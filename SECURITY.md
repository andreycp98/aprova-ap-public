# Política de segurança

## Relato responsável

Não publique vulnerabilidades, dados pessoais, credenciais ou exemplos de
exploração em issues públicas.

Use o recurso **Report a vulnerability** do GitHub quando ele estiver disponível
neste repositório. Caso o recurso não esteja visível, abra uma issue sem dados
sensíveis solicitando um canal privado de contato.

## Escopo deste repositório

Este repositório contém apenas documentação pública sanitizada. O código do
produto e a infraestrutura operacional são privados.

## Compromissos

- investigar relatos de boa-fé;
- reduzir a coleta e exposição de dados;
- manter autorização no servidor e no banco de dados;
- corrigir vulnerabilidades de acordo com risco e impacto.
